# 《还早》网页小游戏项目计划书

## 执行摘要  
本项目目标是为单人开发者打造一款简约的沉浸式网页小游戏。玩家的显性任务是“等公交车”，但实际体验是在一个清晨的生活街区中自由探索、观察和感受。游戏不会有紧张的任务或对话，而是提供一个**小而完整**的场景：公交站、早餐店、街道、公园等，让玩家可以慢下来，感受清晨的日常氛围。最终，玩家可以在游戏结束时写下一段自己的感受，但文字默认不上传服务器，仅在本地保存（或不保存）。项目基于免费开源技术，预计 3 天内可完成原型，最多 4 天打磨上线。  

## 项目定位与内核  
- **表面主线：** 玩家坐在公交站台等待首班车到来。  
- **实际目标：** 在一个清晨的街区里自由行动，重新体验日常生活的宁静与细节；让玩家下了车后更愿意走出家门，关注现实中的街道与人群。  
- **保留元素：** 公交站牌与等待是情感锚点，公交车会如期到来，玩家可选择上车或继续留在站台。  
- **结尾书写：** 游戏末尾提供一个简单的文本框，玩家可以写下一句话或回忆（按需保存到本地或直接关闭）。游戏不强行解释或总结感受，而是让玩家自发思考。  

**核心原则：** 不强制剧情，不刻意煽情；提供一个让玩家重新“慢下来、看细节”的机会。我们借鉴了 Three.js 官网上的建议：使用现代构建工具（如 Vite）可以快速搭建 3D 场景；三维库 Three.js 本身体积小（约150KB）且自由度高，非常适合这种需要最大控制权的定制化场景。

## 场景规模与玩法范围  
- **场景结构：** 一片小街区，包括公交站台、路边早餐店、小公园、数幢低矮建筑和几棵树木，整体步行范围内。街道尽头可以看到模糊的远景天际线。  
- **视角与控制：** 第一人称视角，玩家可以用键盘+鼠标（或触屏点触）自由行走。界面简洁，无任务提示，仅显示极少量 UI。  
- **玩法要素：**   
  - **探索与行动：** 玩家可走进早餐店窗口、坐在街边长椅、穿过公园。  
  - **观察细节：** 街道上的行人会路过（无AI互动，仅动画循环），玩家可驻足观察。  
  - **时间进程：** 清晨逐渐亮起，鸟鸣、风声、汽笛声等环境音营造氛围。首班公交车在设定时间后到站（例如 2–3 分钟模拟），玩家可上车离开或留下。  
- **体验定位：** 桌面网页优先支持，移动端触控适配为次要选项（无需竖屏精致UI）。场景**小而精致**，避免大场景开销。  
- **艺术风格：** 建议采用低多边形/卡通渲染风格，简单而温馨，以节省开发时间与资源加载。

## 技术选型对比  
- **推荐方案：Vite + Three.js（纯代码开发）**  
  - 优点：完全开源免费；Three.js 提供灵活的 3D 渲染组件，无编辑器依赖；Vite 提供 ES 模块热更新、自动处理 glTF/纹理等资源路径；社区庞大教程多。打包体积小，运行时启动迅速。  
  - 缺点：无可视化编辑器，需要编写大量代码；学习曲线取决于开发者对 JS/3D 知识。移动端需自行优化性能。  
- **备选方案1：Babylon.js（一体化3D引擎）**  
  - 优点：功能齐全（内置物理、场景构建器、编辑器）、API 现代化，支持 TypeScript；有在线编辑器可以快速布局。  
  - 缺点：体积较大（依赖丰富）、使用门槛稍高（要理解引擎概念）；项目比较简单时过重。  
- **备选方案2：PlayCanvas（云端3D引擎）**  
  - 优点：内置可视化编辑器，拖放场景；开源引擎（MIT）免费，但编辑器商业化。运行效率好。  
  - 缺点：依赖其在线编辑器生态，离线编辑体验弱；学习成本（需掌握实体组件系统 ECS）略高。  
- **备选方案3：2D框架或无代码工具**（如 Phaser、Construct、GDevelop 等）  
  - 优点：2D框架开发快速、中文资源丰富；无代码工具门槛低。  
  - 缺点：难以还原所需的清晨街区 3D 空间感；场景若用 2D 则美感大打折扣。  

鉴于项目需要表现“真实的街区漫步”，推荐方案依旧是 Three.js+Vite。Vite 文档明确指出，这是无框架的三维项目的“金标准”选择。次优可以考虑 Babylon（较完善的功能）或 Phaser（如放弃3D，只做平面场景）。无论方案，应首选免费开源、免版税的工具和托管。  

**技术选型参考资料：** Three.js 官网上的 Vite 教程和 Cinevva 的引擎对比清晰说明了各方案的定位和权衡。 

## 素材策略  
- **3D模型和纹理：** 优先使用高质量免费库。推荐 **Quaternius**（CC0 许可，专为独立游戏提供低多边形资源）；**Lowpoly3D** 网站提供数百个 CC BY/CC BY-SA 授权的低多边形模型；其它如 **Kenney**、**OpenGameArt** 等也有免费3D资源。若找不到特定资产，可用简单几何体（盒子/柱体）替代。贴图尽量使用低分辨率或 PBR 素材，以加快加载。  
- **音效和音乐：** 采用免费环境音库。如 Kenney 网站提供了免费的背景音乐和音效包（CC0 授权）；Pixabay、FreeSound 可下载城市鸟鸣、脚步声、交通声等环境音，使用时注意过滤 CC0 或明确标注可商用；Mixkit、Zapsplat 等平台也有免费音效素材。音量宜设为较低循环播放。  
- **UI 资源：** 由于 UI 简洁，仅需少量图标或字体。使用系统或 Google Fonts 字体，无需美术资源。按钮、输入框使用 HTML/CSS 实现，样式可简单而清晰。  

> **示例素材：** Pixabay 上有贴合主题的插图，如清晨城市剪影；Unsplash 上也有空长椅公园照片。这些可以作为概念参考图，激发氛围设计。

## 文件结构与关键模块设计  
建议项目目录示例：  
```
/（项目根目录）
├─ index.html           // 主页面（包含<canvas>和结尾输入框）
├─ style.css            // 全局样式（页面重置、canvas 布局、UI 样式）
├─ main.js (或 main.ts) // 入口文件：初始化场景、相机、渲染器、调用其他模块
├─ /src
│   ├─ scene.js         // 场景管理：加载模型、构建静态场景（地面、建筑、道路）
│   ├─ player.js        // 玩家控制：第一人称移动或点击导航
│   ├─ bus.js           // 公交车逻辑：定时出现、移动、触发上车
│   ├─ npc.js (可选)    // 路人对象：简单模型与动画循环
│   ├─ sound.js         // 声音管理：加载并控制环境音和音乐
│   ├─ ui.js            // 用户界面：结尾文本输入和按钮
│   └─ utils.js         // 常用工具函数（如重置场景、时间格式化等）
└─ /assets
    ├─ /models          // 外部 glTF/OBJ 模型（公交车、长椅、路牌等）
    ├─ /textures        // 地面、墙面、天空贴图
    └─ /sounds          // 鸟鸣、风声、公交声音等音频文件
```

**关键模块：**  
- **场景加载（scene.js）：** 设置 Three.js 场景、摄像机、渲染器；加载各类几何体或 glTF 模型（可用 Three.js 的 GLTFLoader）；安排光源（天空盒或 HemisphereLight+点光使环境柔和）。  
- **玩家控制（player.js）：** 实现第一人称或自由视角移动，可用 Three.js 的 `PointerLockControls` 或自定义简单碰撞。支持键盘/鼠标或触屏控制。  
- **环境音/时间线（sound.js）：** 加载背景鸟鸣、风声、城市远音；使用 HTML5 Audio 或 Three.js Audio 对象。可设置延迟触发，如公交到站前响起。  
- **公交到站逻辑（bus.js）：** 使用 JavaScript 计时器或动画时间线，在指定延时后将公交模型加入场景，并让其沿轨迹前
